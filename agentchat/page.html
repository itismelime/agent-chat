Shortcuts and commands

Keys

Alt+↑ / Alt+↓
previous / next project
Alt+1 … Alt+9
project 1–9
Alt+U
next project with unread messages
Alt+N
terminal of the first agent that needs you
Alt+A
start an agent
↑
in an empty message box: your last message again
/
focus the message box
?
this list
Esc
close a menu or panel

Commands in the message box

/start claude
start Claude in this project (or /start codex, /start opencode [model])
/stop <name>
stop an agent started from the page
/term <name>
open its terminal
/remove <name>
remove it from the chat
/local <model> <name>
add an installed local model as a member
//text
post a message that starts with /
